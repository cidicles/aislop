Served from one small droplet

There's no Vercel here. aislop is a home-made deploy platform: a zero-dependency Node client packs a project and streams it over ssh, and a small Python CLI on the server swaps the files in atomically, starts a Docker container with an honest memory cap, and regenerates the Caddy routes.

Static projects cost nothing to run. Containers listen on localhost only, and Caddy terminates TLS and strips each /slug/ before forwarding. WebSockets and server-sent events pass straight through.
